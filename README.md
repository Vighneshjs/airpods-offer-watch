# AirPods Offer Watch

A public GitHub Pages dashboard for saved Apple AirPods Pro 3 price and stock checks from Amazon India and Flipkart.

Expected website: [vighneshjs.github.io/airpods-offer-watch](https://vighneshjs.github.io/airpods-offer-watch/). The URL becomes available after GitHub Pages is configured and deployment succeeds.

This repository contains only static website files and a sanitized status report. Monitoring, email delivery, private configuration, browser data, and credentials stay in a separate private repository. Delivery locations appear as Region 1 and Region 2.

Enable **Settings → Pages → Source → GitHub Actions**. The included Pages workflow deploys on pushes to `main` or a manual workflow run. It does not run the monitor or send email.

The initial report is unknown. A saved report is evidence of a completed check at its timestamp; GitHub schedules and deployments can be delayed. Confirm final retailer stock, fees, and payment terms before buying.
